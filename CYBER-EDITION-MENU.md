# AflatoonMubdi — Cyber Edition

The in-app panel uses a black / neon-blue cyber-security visual identity, terminal-style labels, and visible ownership credit for AFLATOON (أفلاطون).

## Navigation
- شبكة: DNS and network status / socket tuning
- صوت: outgoing microphone processing
- غرفة: local incoming voice processing
- وقت: input/output delay and tempo controls
- أداء: in-process clock controls
- حول: project information and local profiles

There is no VPN or Packet Tunnel component in this project. DNS and socket tuning are process-scoped and do not change the device's public IP or encrypt traffic.
